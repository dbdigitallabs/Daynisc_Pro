Decision Score ≥ 0.85 ? Approve else Queue

Workflow Explanation

The document workflow guarantees high throughput and accuracy. Documents ingested from multiple channels undergo immediate image enhancement before passing to Gemini 1.5 Vision. Extracted entity confidence is scored: high-confidence extractions automatically post to the ledger and sync with TallyPrime via HTTP XML, while lower-confidence items are queued in the Web Dashboard for 1-click human verification.

// ALGORITHM: Daynisc_AI_Document_Ingestion_And_Tally_Sync INPUT : input_file (Image / PDF), tenant_id, channel_type OUTPUT: Verified_Voucher_Entry, Stock_Ledger_Update, Tally_Sync_Status START 1. RECEIVE input_file via (Web Dashboard / Mobile App / WhatsApp Webhook) 2. UPLOAD raw input_file to AWS S3 bucket and get s3_file_uri 3. ENQUEUE async processing task to Celery worker queue with s3_file_uri 4. CALL Gemini_Vision_API(s3_file_uri, Prompt_Schema_JSON) 5. PARSE AI JSON response: { invoice_num, vendor_gstin, date, line_items, total_tax, grand_total } 6. COMPUTE confidence_score C = CalculateTokenConfidence(AI_response) 7. IF C ≥ 0.85 AND ValidateMathRule(line_items, total_tax, grand_total) == TRUE THEN a. INSERT Voucher record into PostgreSQL with status = 'APPROVED' b. GENERATE TallyPrime XML payload and POST to local Tally HTTP port c. UPDATE stock movement inventory ledgers automatically ELSE a. INSERT Voucher record into PostgreSQL with status = 'NEEDS_REVIEW' b. PUSH alert to Web Dashboard Verification Queue for 1-click human review 8. LOG audit trail event with user_id, timestamp, and confidence_score END

RISK & CHALLENGE ANALYSIS

Slide 9 — Technical Challenges & Open Queries

09 / 10
Development Challenges

Realistic Technical Risks

  • Image Quality & Handwriting: Damaged/handwritten bills drop OCR accuracy. Mitigation: Human review queue fallback.
  • AI API Response Latency: Gemini Vision API calls take 2-4 seconds. Mitigation: Non-blocking Celery background workers.
  • Tally Offline Connectivity: Local Tally may go offline in remote factories. Mitigation: Retry queue in Redis.
  • Tenant Security: SME financial data isolation. Mitigation: PostgreSQL schema-per-company separation.
Open Questions

Implementation Queries to Resolve

  • Regional Languages: Tuning prompts for Indian regional language invoices (Hindi, Gujarati).
  • Confidence Threshold: Calibrating optimal cutoff (0.80 vs 0.85) to balance speed vs review load.
  • Template Variance: Generalizing extraction rules across hundreds of unique vendor bill layouts.
  • Mobile Caching: Strategy for offline document capture in low-connectivity factory floors.
