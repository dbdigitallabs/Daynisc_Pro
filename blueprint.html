Security Architecture

Enterprise-grade security with RBAC, OTP login, JWT, multi-tenant isolation, and comprehensive audit logging.

Authentication

  • OTP via SMS (MSG91)
  • JWT Access Token (15m)
  • Refresh Token (30d)
  • Device Fingerprint
  • IP Allowlist (optional)

RBAC Roles

  • Super Admin
  • Company Admin
  • Accountant
  • Inventory Manager
  • Production Supervisor
  • Sales Rep (read)
  • Warehouse Operator

Multi-Tenant

  • Schema-per-company
  • Row-level policies
  • Encrypted secrets
  • Company isolation
  • Cross-tenant block

Audit Trail

  • Every write logged
  • User + IP + timestamp
  • Before/after values
  • Immutable audit table
  • 7-year retention

Security Checklist

HTTPS everywhere (TLS 1.3)
Encrypted S3 documents
Secrets in AWS Secrets Manager
SQL injection prevention (ORM)
Rate limiting per IP
CORS policy enforcement
Input validation (Pydantic)
File type validation (MIME)
Daily encrypted backups
VAPT penetration testing
PII data masking in logs
CSP headers on web app
