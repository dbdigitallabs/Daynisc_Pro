2. How Daynisc Connects to Tally (Protocol & Configuration)

TallyPrime features a native HTTP XML Server running on top of its TDL (Tally Definition Language) engine.

  • Protocol: Standard HTTP (POST/GET)
  • Default Port: 9000 (URL: http://localhost:9000 or local network IP)
  • Payload Format: Tally XML Envelope (text/xml; charset=utf-8)
  • Prerequisites in Tally:
    1. Open TallyPrime > Press F1 (Help) > Settings > Connectivity.
    2. Set TallyPrime acts as to Both or Server.
    3. Set Port to 9000.
    4. Restart TallyPrime.

3. Python Libraries Used & Why

Library Used In Why We Use It
httpx (0.28.1) tally_connector.py High-performance async HTTP client. Handles non-blocking requests in FastAPI and Celery workers with configurable timeout safeguards.

pydantic & pydantic-settings config.py Strong type validation for Tally configuration (TALLY_DEFAULT_URL, TALLY_TIMEOUT).

4. API Reference

Internal FastAPI Endpoints (backend/erp_router.py)

Method Endpoint Purpose
GET /api/v1/erp/connection/test/tally Tests connectivity with Tally HTTP port 9000 and verifies signature.
POST /api/v1/erp/sync/voucher/{voucher_id} Triggers manual 1-click sync for an individual approved voucher.
POST /api/v1/erp/sync/bulk Batches and pushes up to 100 pending vouchers from the last 30 days.
GET /api/v1/erp/status Fetches sync statistics (pending, synced, error counts).

External Tally Native XML APIs (backend/tally_connector.py)

  • Purchase Voucher: <VOUCHER VCHTYPE="Purchase" ACTION="Create"> — Credits Sundry Creditor, debits purchase ledger, calculates CGST/SGST/IGST, and logs Godown inventory allocations.
  • Sales Voucher: <VOUCHER VCHTYPE="Sales" ACTION="Create"> — Debits Sundry Debtor, credits revenue and output GST ledgers.
  • Payment & Receipt: <VOUCHER VCHTYPE="Payment"> / <VOUCHER VCHTYPE="Receipt"> — Manages party vs bank/cash ledger reconciliations.
  • Stock Journal: <VOUCHER VCHTYPE="Stock Journal"> — Tracks factory raw material consumption vs produced finished goods.
  • Ledger Master Creation: <LEDGER ACTION="Create"> — Automatically creates party ledgers with GSTIN, address, state, and pin code before voucher posting.
  • Export Ping: <TALLYREQUEST>Export</TALLYREQUEST> for List of Companies — Heartbeat ping verifying Tally is running.
